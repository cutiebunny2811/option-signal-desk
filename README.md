# Option Signal Desk

Dashboard แยกสำหรับอ่านข้อมูลหุ้นและออปชันจาก Portfolio Command Center (PCC) โดยไม่ส่งคำสั่งซื้อขาย

## ใช้งาน

- เข้าเว็บด้วยบัญชี Supabase เดียวกับ PCC
- รายการ “หุ้นเฝ้าเทรด” แยกจาก Watchlist PCC เริ่มต้น QQQ, NVDA, GOOGL, RKLB, IREN; เพิ่ม/ลบได้สูงสุด 10 ตัวและซิงก์ตามบัญชีผ่าน Supabase โดยมีสำเนาใน `localStorage`
- ตอนเพิ่มให้เลือก “หุ้น” หรือ “ETF”; หากยังไม่มีระเบียน `instruments` ระบบใช้ `api_upsert_instrument` ของ PCC สร้างระเบียนให้โดย **ไม่** เพิ่มใน Watchlist PCC การลบจากรายการเฝ้าไม่ลบระเบียนหรือข้อมูลพอร์ต
- เลือกหุ้นจากรายการเฝ้าหรือพิมพ์ ticker เพื่อเปิดดูหุ้นอื่นชั่วคราว
- แถบหุ้นเฝ้าแสดง “เฝ้า CALL/PUT” เมื่อแท่ง 1m+5m ที่ปิดแล้วและสดไปทางเดียวกัน โดย 15m ต้องไม่สวนทาง; ป้าย “เร็ว 2/3” หมายถึง 15m ยังไม่ยืนยัน ส่วน “3/3” คือแท่งสั้นทั้งสามตรงกัน 1h เป็นบริบทย้อนหลัง ไม่บังคับรอ
- ดูทิศทาง 1m / 5m / 15m / 1h จาก EMA9, EMA21 และ RSI14, กราฟหุ้น, OI ของ Call/Put รอบราคา และรายละเอียดสัญญา
- การ์ดแต่ละ TF แสดงราคาปิดและเวลาปิดของแท่งล่าสุดเป็นเวลาไทย จึงเห็นชัดว่าเลขต่างกันเพราะอ้างอิงคนละแท่ง; แกนเวลากราฟและ crosshair ใช้เวลาไทยเช่นกัน ส่วนราคาหุ้นด้านบนเป็น quote ของ Option chain ซึ่งอัปเดตคนละรอบ
- ดู Forecast* และระดับ Entry / SL / TP1 / TP2 ของราคาหุ้น โหมด CALL/PUT เป็นระดับจำลองเท่านั้น โหมด “ตามสัญญาณ” จะล็อก setup เมื่อเงื่อนไขครบ แล้วแสดงวงจร “เฝ้าทะลุ → ทะลุยืนยัน → ติดตาม TP/SL” หรือเหตุผลที่ยกเลิก/พลาดจุดเข้า
- VWAP วันเป็นตัวกรองจุดเข้าเฉพาะโหมด “ตามสัญญาณ” ไม่วาดบนกราฟและไม่เปลี่ยน Entry/SL/TP: CALL ต้องปิดเหนือ VWAP, PUT ต้องปิดต่ำกว่า VWAP ทั้งตอนล็อกและตอนแท่ง 1m ยืนยัน; ถ้าแท่งหรือ volume ตั้งแต่เปิดตลาดไม่ครบ ระบบรอข้อมูล ไม่ใช้ค่าเดา
- กด OI ในแถว strike หรือเลือกรายการสัญญาเพื่อดู bid/ask, spread, Delta, IV, Volume/OI, ต้นทุนที่ Ask และจุดคุ้มทุน ณ หมดอายุ
- เมื่อกดเปิด Push ของอุปกรณ์ Supabase จะสแกนเฉพาะหุ้นเฝ้าช่วงตลาดเปิด แม้ปิดหน้าเว็บ แจ้งเมื่อทิศทางแท่งสั้น **เพิ่ง** เปลี่ยนเป็นฝั่ง CALL/PUT; กด “ทดสอบส่งแจ้งเตือน” เพื่อตรวจการส่งจริง บน iPhone ต้องเพิ่มเว็บไปหน้าจอหลักและเปิดจากไอคอนก่อน
- หุ้นที่กำลังเปิดดูอยู่ใช้เงื่อนไขเดิมของแผนที่ล็อกไว้; แจ้งเมื่อแท่ง 1m ปิดผ่าน Entry, แตะ TP1/SL หรือข้อมูลขาดช่วงเฉพาะขณะหน้าเว็บทำงาน แผนนี้เก็บในเบราว์เซอร์ ไม่ใช่การส่งคำสั่งซื้อขาย
- มุม “จดผลเทรดทดลอง” บันทึก **เฉพาะ Option Demo ที่ปิดแล้ว** แบบกรอกเร็ว: สัญญา, CALL/PUT, จำนวน, ยอดซื้อรวม/ขายรวม USD, ค่าธรรมเนียม, เวลาเปิด/ปิด และเลือกเองว่า “ตามสัญญาณแอป” หรือไม่; สรุป P/L สุทธิ, เวลาถือ, จำนวนชนะ/แพ้ และส่งออก CSV ได้ รายการนี้ไม่แก้พอร์ตจริงหรือส่งคำสั่งซื้อขาย

## จดผล Demo และที่เก็บข้อมูล

- สูตร P/L = ยอดขายรวม − ยอดซื้อรวม − ค่าธรรมเนียมที่กรอก ทั้งสามช่องเป็น **ยอดรวมทั้งรายการ** ไม่ใช่ premium ต่อหุ้น; ผลตอบแทนแต่ละรายการ = P/L ÷ ยอดซื้อรวม × 100 (ถ้ายอดซื้อเป็น 0 จะแสดง —); เวลาถือ = เวลาปิด − เวลาเปิด (ช่องเวลาที่แสดงเป็นเวลาไทย)
- กด **แนบรูป Filled** แล้วแนบ/วางรูป Webull คำสั่งซื้อและขายคนละช่อง (PNG/JPG/WebP ไม่เกิน 10 MB ต่อรูป) ระบบอ่านด้วย Tesseract.js ในเบราว์เซอร์โดยไม่อัปโหลดรูปเข้า Supabase; ครั้งแรกต้องโหลดตัวอ่านภาพ/ภาษาไทยจาก CDN และอาจช้า จากนั้นตรวจว่าสัญญาและจำนวนซื้อ–ขายตรงกัน แล้วเติมฟอร์มให้ตรวจและกดบันทึกเอง **ยังไม่บันทึกอัตโนมัติ** เพราะ OCR อาจอ่านผิด
- ระบบใช้ **ราคาเฉลี่ยที่ Filled × จำนวนสัญญา × 100** และ **เวลาที่จับคู่สำเร็จ** ไม่ใช้ราคาลิมิต ราคากลาง หรือเวลาส่งคำสั่ง แปลง EDT/EST เป็นเวลาไทย; ตอนนำเข้าค่าธรรมเนียมเป็น 0 และ “ตามสัญญาณแอป” ไม่ถูกติ๊กอัตโนมัติ ผู้ใช้ต้องตรวจ/แก้สองช่องนี้ก่อนบันทึก รองรับรายการที่ซื้อและขายปิดครบจำนวนเดียวกันก่อน (ไม่รวมปิดหลายไม้หรือข้ามหลายภาพ)
- ค่าเริ่มต้นสถิติ “ตามแอป” นับเฉพาะรายการที่ผู้ใช้ติ๊กว่าตามสัญญาณและปิดแล้ว; กด “ทั้งหมด” เพื่อรวมรายการทดลองเองด้วย Win rate = ชนะ ÷ (ชนะ + แพ้) โดยรายการเสมอไม่นับในตัวหาร นี่คืออัตราชนะของ **รายการที่จด** ไม่ใช่ความแม่นของทุกสัญญาณหรือผล backtest
- รายการแก้ไขได้; ปุ่ม “ยกเลิก” ทำเครื่องหมายไม่นับในสถิติโดยไม่ลบแถวข้อมูลจาก Supabase การส่งออก CSV มีรายการที่ใช้งานอยู่ทั้งหมด (ไม่รวมที่ยกเลิก)
- ประวัติแสดงทีละ 10 รายการพร้อมปุ่มเปลี่ยนหน้าและค้นหา ticker/strike (ไม่ตัดทิ้งเมื่อเกิน 100 รายการ) บนมือถือแต่ละรายการแสดงสัญญา ผลลัพธ์ และวันปิดแบบย่อ; แตะเพื่อขยายยอดซื้อ–ขาย เวลาถือ และปุ่มแก้ไข/ยกเลิก สถิติด้านบนยังคำนวณจากทุกรายการในตัวกรอง ไม่ใช่เฉพาะหน้าที่เห็นหรือคำค้น
- เมื่อติดตั้ง `supabase/20261022_option_desk_demo_trades.sql` ใน **Supabase project เดียวกับ PCC** แล้ว เว็บจะซิงก์ตาราง `option_desk_demo_trades` โดยสิทธิ์ RLS แยกตามบัญชีผู้ใช้ หากตารางยังไม่พร้อมหรือเครือข่ายมีปัญหา จะบันทึกใน `localStorage` ของเบราว์เซอร์นั้นและแสดงสถานะ “เก็บในเครื่อง”; ควรกด **ส่งออก CSV สำรอง** เพราะข้อมูลในเครื่องอาจหายเมื่อเปลี่ยนอุปกรณ์หรือล้างข้อมูลเบราว์เซอร์ กด “ซิงก์อีกครั้ง” หลังตั้งตาราง/กลับมาออนไลน์
- ไฟล์ SQL นี้เป็น migration ใหม่ ไม่แตะ `executions` หรือ `journal_entries` ของ PCC และไม่ใส่ข้อมูล Demo ลงยอดพอร์ตจริง ก่อนใช้ซิงก์ข้ามเครื่อง ผู้ดูแลต้องรัน SQL และตรวจว่า UI ขึ้น “ซิงก์ Supabase” ด้วยบัญชีจริง

หน้าเว็บเรียก `refresh-stock-prices` Edge Function ที่ PCC มีอยู่แล้วด้วย JWT ของสมาชิก Webull key และ service role key อยู่ฝั่ง Supabase เท่านั้น สิทธิ์ OPRA ใน Edge Function จำกัดเฉพาะเจ้าของ subscription ตาม `OPTIONS_OPRA_OWNER_USER_ID` ของ PCC

## ความสดและโควต้า

- หน้านี้ดึง Option chain เฉพาะหุ้นที่กำลังเปิดดู ส่วนรายการเฝ้าใช้กราฟ M1 เท่านั้นเพื่อคำนวณ 1m/5m/15m ไม่ดึง 1h หรือ OPRA ทุกตัว
- ช่วงตลาดหุ้นสหรัฐฯ เปิดและแท็บอยู่ด้านหน้า: เช็กกราฟ 1 นาทีทุก 2 นาที และ Option quote ทุก 3 นาที; กราฟ 1 ชั่วโมงใช้เป็นบริบทของหุ้นที่เปิดดู ดึงแยกหลังสัญญาณสั้นและเช็กไม่ถี่กว่า 45 นาที
- สัญญาณใช้แท่ง 1m/1h ที่ปิดแล้วเท่านั้น; 5m/15m รวมจากแท่ง 1m ที่ปิดครบแล้ว จึงไม่เสียคำขอเพิ่ม; 4h/1D ดึงเมื่อเลือกกราฟนั้น ทุก TF ตรวจทั้งเวลาแท่งและเวลาที่ดึงข้อมูล: snapshot ที่ถูกดึงระหว่างแท่งวิ่งอยู่จะไม่กลายเป็น “แท่งปิด” เพียงเพราะเวลาผ่านไป
- แท่ง 4h/1h สุดท้ายของ regular session อาจสั้นกว่าช่วงปกติและจะนับว่าปิดเมื่อมีข้อมูลที่ดึงหลังตลาดปิดพร้อม margin 10 นาที; แท่ง 1D ของวันปัจจุบันรอข้อมูลหลัง 16:10 น. นิวยอร์ก
- หน้าเว็บพักเมื่อซ่อนแท็บและอ่านข้อมูลใหม่เมื่อกลับมา แต่ไม่หยุดเพียงเพราะไม่มีการแตะ 20 นาที; กดรีเฟรชด้วยมือได้แต่จำกัดอย่างน้อย 30 วินาทีต่อครั้ง; พบ 429 หน้าเว็บพัก 10 นาที
- เวลา quote และกราฟแสดงแยกกัน ถ้า 1m/5m เก่าหรือตลาดปิดให้ WAIT; 1h เก่าแสดงได้เพียงบริบทย้อนหลัง ไม่เป็นตัวคอนเฟิร์ม
- เมื่อเปิด Push เซิร์ฟเวอร์ทำงานทุกนาที สูงสุด 2 หุ้นต่อรอบและไม่น้อยกว่า 3 นาทีต่อหุ้น; ถ้าเจอ 429 พักหุ้นนั้น 15 นาที แท็บที่เปิดอยู่ไม่สแกนรายการซ้ำ แต่ยังรีเฟรชหุ้นที่กำลังดูและ Option quote ตามรอบปกติ
- แผนที่ล็อกเก็บใน browser ของบัญชีนั้นแยกตาม ticker และวันตลาดนิวยอร์ก; เปิดแท็บใหม่แล้วกลับมาดูได้ แต่หากช่วงที่ไม่ได้เปิดข้อมูลขาดเกิน 4 นาที ระบบหยุดแผน ไม่เติมสัญญาณย้อนหลัง

นี่คือการ poll อย่างประหยัด ไม่ใช่ WebSocket tick-by-tick; เวลาเจอสัญญาณของหุ้นที่ไม่ได้เปิดดูอาจช้ากว่าตลาดหลายนาที Push หลังปิดเว็บใช้กับการเปลี่ยนทิศทางหุ้นเฝ้าเท่านั้น ไม่รับประกันว่า Webull จะส่งข้อมูลใหม่ถี่เท่ารอบ poll หรือว่าเครือข่ายอุปกรณ์จะส่งทันที

## ข้อจำกัดที่ยังมี

- 2/3 และ 3/3 คือจำนวนแท่งสั้นที่เข้าเงื่อนไขราคา/EMA/RSI ไม่ใช่เปอร์เซ็นต์ความสำเร็จหรือจุดเข้าที่ทดสอบย้อนหลัง; 1h ย้อนหลังเป็นบริบทเท่านั้น
- แจ้งเตือนหุ้นเฝ้าตัวอื่นเป็นเพียงทิศทางกราฟแท่งสั้น ไม่ผ่านด่าน quote/spread/OI ของสัญญา; เปิดหุ้นนั้นและตรวจแผน/สัญญาก่อนตัดสินใจ
- ประวัติ OI รายวันหรือ OI change; ข้อมูล OI ที่เห็นเป็น snapshot ล่าสุด
- OI ทุก strike ทุก expiry; PCC ส่งสูงสุด 20 strike ใกล้ราคา **ต่อฝั่ง**
- จุดเข้า, TP, SL เป็นราคาหุ้นตามกฎด้านล่าง ไม่ใช่ราคา option premium, การคำนวณ P/L ของสัญญา, หรือคำสั่งซื้อขาย แผนยังไม่ผ่าน backtest/forward validation และไม่มีคะแนนความน่าจะเป็น
- Quote เป็น snapshot ทุก 3 นาทีและกราฟ poll ทุก 2 นาที จึงไม่ใช่ tick-by-tick execution feed; เมื่อแผนขึ้น “ทะลุยืนยัน” ต้องตรวจกราฟและ bid/ask ของสัญญาใน broker อีกครั้งก่อนตัดสินใจ

## สูตรระดับราคา

- EMA9/EMA21 คำนวณจากราคาปิด; ATR14 ใช้ Wilder smoothing ของ true range
- Forecast* = EMA9 ล่าสุด + (EMA9 ล่าสุด − EMA9 เมื่อ 3 แท่ง 5m ก่อน) เป็นการลากเส้นต่ออีก 15 นาที ไม่ใช่โมเดลทำนายราคา
- CALL Entry = สูงสุด 10 แท่ง 5m ล่าสุด + 0.1 ATR; PUT Entry = ต่ำสุด 10 แท่ง − 0.1 ATR
- SL อยู่เลย swing 5 แท่งฝั่งตรงข้ามและห่าง Entry อย่างน้อย 0.8 ATR; ถ้าเสี่ยงเกิน 3 ATR จะแสดงเป็นระดับอ้างอิง/WAIT เท่านั้น และถ้าเกิน 8 ATR จะไม่สร้างระดับ
- R = |Entry − SL|; TP1 = 1R และ TP2 = 1.8R ในทิศที่เฝ้าดู
- กติกาล็อก: ต้องมีทิศทาง 1m+5m ตรงกันจากแท่งปิดสด และ 15m ไม่สวนทาง, ราคาหุ้นอยู่ฝั่ง VWAP ที่สอดคล้องกัน, R ไม่เกิน 3 ATR, และสัญญาฝั่งเดียวกับสัญญาณที่เลือกมี bid > 0, ask ≥ bid, quote ไม่เกิน 5 นาที, spread ≤ 10% ของ mid, volume ≥ 10, OI ≥ 100 เกณฑ์สภาพคล่องนี้เป็นตัวกรองเริ่มต้นที่ตั้งใจให้อนุรักษ์นิยม ไม่ใช่มาตรฐานสากลหรือการรับประกันว่าจะได้ราคานั้น
- VWAP วันคำนวณจากแท่ง 1m ที่ปิดแล้วในช่วงตลาดปกติ 9:30–16:00 นิวยอร์ก โดยใช้ typical price `(high+low+close)/3` ถ่วงด้วย volume และเริ่มสะสมใหม่ทุกวัน; ต้องมีแท่งตั้งแต่ 9:30 ต่อเนื่องและ volume ถูกต้อง จึงนำมาคัดกรองฝั่งที่เข้า ไม่ใช้เป็น SL/TP หรือคะแนนความน่าจะเป็น
- ล็อก Entry/SL/TP จากแท่ง 5m ที่ปิดแล้ว และเฝ้าไม่เกิน 30 นาที; ใช้เฉพาะแท่ง 1m ใหม่หลังล็อก ก่อนทะลุ หากราคาเปิดเลย Entry, ปิดเลย Entry เกิน 0.25R, quote/ทิศทางแท่งสั้นหลุด หรือแท่งขาดช่วง จะไม่ไล่ราคา/ยืนยันย้อนหลัง
- “ทะลุยืนยัน” ต้องมีแท่ง 1m ใหม่ปิดผ่าน Entry; TP/SL หลังจากนั้นเป็นเพียงการติดตาม **ราคาหุ้น** ถ้า TP และ SL อยู่ในแท่งเดียวกัน ระบบระบุว่าลำดับไม่ชัด ไม่สรุปผลกำไรขาดทุน

OI สูงเป็นเพียงจุดรวมสถานะสัญญา ไม่ใช่หลักฐานว่าฝั่งซื้อหรือฝั่งขายกำลังชนะ OI เป็นยอดสิ้นวัน ไม่ได้เปลี่ยนทุกครั้งที่ราคา option ขยับ
