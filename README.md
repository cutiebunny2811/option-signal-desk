# Option Signal Desk

Dashboard แยกสำหรับอ่านข้อมูลหุ้นและออปชันจาก Portfolio Command Center (PCC) โดยไม่ส่งคำสั่งซื้อขาย

## ใช้งาน

- เข้าเว็บด้วยบัญชี Supabase เดียวกับ PCC
- เลือกหุ้นจาก Watchlist หรือพิมพ์ ticker
- ดูทิศทาง 1m / 5m / 15m / 1h จาก EMA9, EMA21 และ RSI14, กราฟหุ้น, OI ของ Call/Put รอบราคา และรายละเอียดสัญญา
- ดู Forecast* แบบต่อความชัน EMA9 ไป 15 นาที และระดับ Entry / SL / TP1 / TP2 ของราคาหุ้นเมื่อสัญญาณ 4/4 กับ option quote สดตรงกัน; กด “สูตรคำนวณระดับราคา” ใต้กราฟเพื่อดูที่มา
- กด OI ในแถว strike หรือเลือกรายการสัญญาเพื่อดู bid/ask, spread, Delta, IV, Volume/OI, ต้นทุนที่ Ask และจุดคุ้มทุน ณ หมดอายุ

หน้าเว็บเรียก `refresh-stock-prices` Edge Function ที่ PCC มีอยู่แล้วด้วย JWT ของสมาชิก Webull key และ service role key อยู่ฝั่ง Supabase เท่านั้น สิทธิ์ OPRA ใน Edge Function จำกัดเฉพาะเจ้าของ subscription ตาม `OPTIONS_OPRA_OWNER_USER_ID` ของ PCC

## ความสดและโควต้า

- หน้านี้ดึงเฉพาะหุ้นที่กำลังเปิดดู ไม่ไล่อ่านทั้ง watchlist จาก Webull
- ช่วงตลาดหุ้นสหรัฐฯ เปิดและแท็บอยู่ด้านหน้า: เช็กกราฟ 1 นาทีทุก 2 นาที และ Option quote ทุก 3 นาที; กราฟ 1 ชั่วโมงเช็กทุก 10 นาที โดยเรียก Webull เมื่อแคชหมดอายุหรือแท่งปิดล่าสุดเก่าเกินหนึ่งรอบแท่ง
- สัญญาณใช้แท่ง 1m/1h ที่ปิดแล้วเท่านั้น; 5m/15m รวมจากแท่ง 1m ที่ปิดครบแล้ว จึงไม่เสียคำขอเพิ่ม; 4h/1D ดึงเมื่อเลือกกราฟนั้น
- พักอัตโนมัติเมื่อตลาดปิด, ซ่อนแท็บ หรือไม่มีการโต้ตอบ 20 นาที; กดรีเฟรชด้วยมือได้แต่จำกัดอย่างน้อย 30 วินาทีต่อครั้ง; พบ 429 จะพัก 10 นาที
- เวลา quote และกราฟแสดงแยกกัน ข้อมูลเก่าหรือตลาดปิดให้ WAIT และไม่แสดง 4/4 เป็นสัญญาณสด
- Watchlist ด้านซ้ายอ่าน snapshot ใน PCC ทุก 15 นาทีขณะเปิดหน้า ไม่สั่งรีเฟรชทั้งจักรวาลหุ้นผ่าน Webull

นี่คือการ poll อย่างประหยัด ไม่ใช่ WebSocket tick-by-tick และไม่รับประกันว่า Webull จะส่งข้อมูลใหม่ถี่เท่ารอบ poll

## ข้อจำกัดที่ยังมี

- 4/4 คือการเรียงตัวของราคา/EMA และ RSI ใน 4 ช่วงเวลา ไม่ใช่เปอร์เซ็นต์ความสำเร็จหรือจุดเข้าที่ทดสอบย้อนหลัง
- ประวัติ OI รายวันหรือ OI change; ข้อมูล OI ที่เห็นเป็น snapshot ล่าสุด
- OI ทุก strike ทุก expiry; PCC ส่งสูงสุด 20 strike ใกล้ราคา **ต่อฝั่ง**
- จุดเข้า, TP, SL ที่เห็นเป็นแผนเงื่อนไขจากกราฟ 5m ตามกฎด้านล่าง ยังไม่มีการทดสอบย้อนหลังหรือคะแนนความน่าจะเป็น; ไม่ใช่ราคา option premium และไม่ใช่คำสั่งซื้อขาย

## สูตรระดับราคา

- EMA9/EMA21 คำนวณจากราคาปิด; ATR14 ใช้ Wilder smoothing ของ true range
- Forecast* = EMA9 ล่าสุด + (EMA9 ล่าสุด − EMA9 เมื่อ 3 แท่ง 5m ก่อน) เป็นการลากเส้นต่ออีก 15 นาที ไม่ใช่โมเดลทำนายราคา
- CALL Entry = สูงสุด 10 แท่ง 5m ล่าสุด + 0.1 ATR; PUT Entry = ต่ำสุด 10 แท่ง − 0.1 ATR
- SL อยู่เลย swing 5 แท่งฝั่งตรงข้ามและห่าง Entry อย่างน้อย 0.8 ATR; ถ้าเสี่ยงเกิน 3 ATR จะไม่สร้างแผน
- R = |Entry − SL|; TP1 = 1R และ TP2 = 1.8R ในทิศที่เฝ้าดู

OI สูงเป็นเพียงจุดรวมสถานะสัญญา ไม่ใช่หลักฐานว่าฝั่งซื้อหรือฝั่งขายกำลังชนะ OI เป็นยอดสิ้นวัน ไม่ได้เปลี่ยนทุกครั้งที่ราคา option ขยับ

## Preview ในเครื่อง

รันเว็บเซิร์ฟเวอร์แบบ static เช่น `python -m http.server 4173` แล้วเปิด `http://localhost:4173/?preview=1` เพื่อดูข้อมูลตัวอย่าง โหมดนี้ใช้ได้เฉพาะ localhost และแสดงป้าย DEMO ชัดเจน

## Deploy

GitHub Pages จาก root ของ branch `main` แบบเดียวกับ PCC ไม่ต้องมี build step `config.js` มีเพียง Supabase URL และ publishable key ซึ่งตั้งใจให้ใช้ใน browser; ห้ามเพิ่ม Webull secrets, Supabase service role key หรือข้อมูลบัญชีใน repo
